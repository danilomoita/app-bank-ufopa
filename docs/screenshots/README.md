# Capturas das interfaces

Salve aqui as capturas usadas para demonstrar o App Bank no GitHub.

## Nomes sugeridos

- `terminal.png`: menus e uma operação concluída no terminal.
- `gui.png`: janela gráfica com um titular, uma conta e saldo selecionados.

Utilize somente dados fictícios e mantenha os textos legíveis. As capturas
demonstram o aplicativo, mas não são utilizadas para sua execução.

Após adicionar as imagens, descomente os blocos de demonstração no README
da raiz. No Markdown desse README, os caminhos são:

```markdown
![Interface de terminal do App Bank](docs/screenshots/terminal.png)
![Interface gráfica do App Bank](docs/screenshots/gui.png)
```

Para enviar as capturas em um commit posterior, na raiz do projeto:

```shell
git add docs/screenshots README.md
git commit -m "docs: adiciona capturas das interfaces"
git push
```
